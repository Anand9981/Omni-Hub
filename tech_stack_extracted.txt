3.2 Relationships in MongoDB
PostgreSQL Foreign Keys → MongoDB ObjectId references + Mongoose `populate()`
Unique Constraints → Mongoose `unique: true` in schema
Check Constraints → Mongoose custom validators
Triggers → Mongoose middleware (`pre('save')`, `post('save')`)
Example:
// PostgreSQL: conversation_id FOREIGN KEY// MongoDB:conversation_id: {type: mongoose.Schema.Types.ObjectId,ref: 'Conversation',required: true}
